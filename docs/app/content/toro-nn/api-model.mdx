Reflection-based parameter discovery, serialization, and deserialization for F# record models.

| Function | Description |
| --- | --- |
| `loadFromDict model tensors nameMap mode` | Load tensors from a dictionary into the model, matching by parameter name. |
| `loadInto model filePath mode` | Load tensors from a .safetensors file into the model in place. |
| `namedParams model` | Return all named tensors in the model via reflection. |
| `save model filePath` | Save all model tensors to a .safetensors file. |
| `trainableVars model` | Return all tensors that require gradients. |

## Types

### LoadReport

```fsharp
type LoadReport = {
    Loaded: string list
    Missing: string list
    Unexpected: string list
}
```

### LoadMode

```fsharp
type LoadMode =
    | Strict
    | Lenient
```

`Strict` returns an error when there are missing or unexpected keys.
`Lenient` always succeeds and reports mismatches in the `LoadReport`.

---

## loadFromDict

```fsharp
loadFromDict model tensors nameMap mode
```

Load tensors from a dictionary into the model, matching by parameter name.
When nameMap is Some, dictionary keys are translated before matching.

**Parameters**

- `model` : `'T`
- `tensors` : `Map<string, Tensor>`
- `nameMap` : `Map<string, string> option`
- `mode` : `LoadMode`

**Returns** `Result<LoadReport, ToroError>`

---

## loadInto

```fsharp
loadInto model filePath mode
```

**Parameters**

- `model` : `'T`
- `filePath` : `string`
- `mode` : `LoadMode`

**Returns** `Result<LoadReport, ToroError>`

## namedParams

```fsharp
namedParams model
```

**Parameters**

- `model` : `'T`

**Returns** `(string * Tensor) list`

## save

```fsharp
save model filePath
```

Save all model tensors to a .safetensors file. Validates that parameter names are unique.

**Parameters**

- `model` : `'T`
- `filePath` : `string`

**Returns** `Result<unit, ToroError>`
