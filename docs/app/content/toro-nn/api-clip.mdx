Gradient clipping utilities.

| Function | Description |
| --- | --- |
| `gradNorm maxNorm vars` | Clip gradients by global L2 norm. Return the total norm before clipping. |
| `gradValue value vars` | Clip each gradient element to [-value, +value]. |

## gradNorm

```fsharp
gradNorm maxNorm vars
```

Clip gradients by global L2 norm. Return the total norm before clipping.

**Parameters**

- `maxNorm` : `float`
- `vars` : `Tensor list`

**Returns** `float`
