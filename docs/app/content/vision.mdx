Toro.Vision provides composable image transforms for preprocessing and data augmentation.
Open the namespace to get started:

```fsharp
open Toro
open Toro.Vision
```

## ITransform

All transforms implement `ITransform`:

```fsharp
type ITransform =
    abstract apply: Tensor -> Result<Tensor, ToroError>
```

Input tensors are expected in `[C, H, W]` or `[B, C, H, W]` format with `float32` values.

## Available Transforms

### Normalize

Channel-wise normalization: $(x - \mu) / \sigma$.

```fsharp
let norm: ITransform = { Normalize.Mean = [ 0.485; 0.456; 0.406 ]; Std = [ 0.229; 0.224; 0.225 ] }

// Or use the ImageNet preset:
let norm = Normalize.imageNet
```

### Resize

Resize spatial dimensions using bilinear interpolation:

```fsharp
let resize = Resize.create 224 224
```

### RandomHorizontalFlip

Flip the image horizontally with a given probability:

```fsharp
let flip = RandomHorizontalFlip.create 0.5

// Or use the default (p = 0.5):
let flip = RandomHorizontalFlip.defaultFlip
```

### RandomCrop

Randomly crop the image to the specified size:

```fsharp
let crop = RandomCrop.create 224 224
```

Returns `Error` if the input is smaller than the crop size.

## Compose

Chain multiple transforms into a single pipeline with `Compose.apply`.
Execution short-circuits on the first error:

```fsharp
result {
    let! img = Tensor.randn ([ 3; 256; 256 ], F32, Cpu)

    let transforms = [
        Resize.create 224 224
        RandomHorizontalFlip.defaultFlip
        Normalize.imageNet
    ]

    let! processed = Compose.apply transforms img
    // processed: [3, 224, 224], normalized
}
```

## Training vs. Inference Pipeline

```fsharp
let trainTransforms = [
    Resize.create 256 256
    RandomCrop.create 224 224
    RandomHorizontalFlip.defaultFlip
    Normalize.imageNet
]

let evalTransforms = [
    Resize.create 224 224
    Normalize.imageNet
]
```
