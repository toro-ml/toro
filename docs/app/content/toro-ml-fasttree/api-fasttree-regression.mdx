# RegressionConfig

Common FastTree regression settings.

## Record fields

| Name | Description |
| --- | --- |
| `LearningRate` | Shrinkage rate applied to each tree. |
| `MinimumExampleCountPerLeaf` | Minimum number of examples required in a leaf. |
| `NumberOfLeaves` | Maximum number of leaves in each tree. |
| `NumberOfTrees` | Number of trees in the ensemble. |
| `Seed` | Random seed. The default is `Some 0` for reproducibility. |

# Regression

FastTree regression operations.

| Function | Description |
| --- | --- |
| `evaluate dataset model` | Evaluate a fitted regressor with ML.NET regression metrics. |
| `fit config dataset` | Fit a FastTree regressor with common F# settings. |
| `fitWithOptions seed configure dataset` | Fit a FastTree regressor after configuring the complete ML.NET options object. |
| `load path` | Load a FastTree regression model from the ML.NET zip format. |
| `predict features model` | Predict target values. Values are returned as a detached CPU float32 tensor. |
| `save path model` | Save a fitted model in the ML.NET zip format. |
