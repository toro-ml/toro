# JsonConfig

JSON configuration helpers for Toro model-family packages.

| Function | Description |
| --- | --- |
| `boolValue label root name` | Read a required Boolean property. |
| `floatValue label root name` | Read a required floating-point property. |
| `int64Element label name value` | Read an integer JSON element. |
| `int64Value label root name` | Read a required integer property. |
| `property label root name` | Get a required object property. |
| `stringValue label root name` | Read a required string property. |
| `tryProperty root name` | Find an optional object property. |
| `validateObject label root` | Validate that a configuration root is an object without duplicate keys. |

# FixedKvCache

Fixed-capacity key/value storage shared by Toro causal model-family packages.

## Constructors

| Name | Description |
| --- | --- |
| `FixedKvCache(ownerName, layerCount, batchSize, headCount, capacity, headSize, dtype, device)` |  |

## Instance members

| Name | Description |
| --- | --- |
| `this.Advance` | Advance the logical cache length after every layer has appended. |
| `this.Append` | Append one layer's key and value tensors and return the populated views. |
| `this.BatchSize` | Number of batch items stored by the cache. |
| `this.Capacity` | Maximum number of tokens stored by the cache. |
| `this.Length` | Number of tokens currently stored by the cache. |
| `this.Reset` | Remove all logical entries without reallocating storage. |
| `this.Validate` | Validate an input batch and sequence against the cache state. |

# PreparedCausalInput

Validated and normalized causal model input for model-family packages.

## Record fields

| Name | Description |
| --- | --- |
| `AttentionMask` | Broadcastable padding and causal mask when an explicit mask is required. |
| `CacheStart` | Number of cached tokens preceding this invocation. |
| `IsCausal` | Whether the attention implementation should apply its built-in causal mask. |
| `PositionIds` | Validated or generated absolute token positions. |
| `SequenceLength` | Number of input tokens processed in this invocation. |
