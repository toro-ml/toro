# Image

Image I/O and SKBitmap-Tensor conversion.

| Function | Description |
| --- | --- |
| `fromTensor tensor` | Convert a [3, H, W] float32 tensor in [0, 1] to an SKBitmap. |
| `load path device` | Load an image file as a [3, H, W] float32 tensor in [0, 1]. |
| `loadStream stream device` | Load an image from a stream as a [3, H, W] float32 tensor in [0, 1]. |
| `save tensor path format _quality` | Save a [3, H, W] float32 tensor as an image file. |
| `saveGrid tensor path format quality nrow` | Save a batch tensor [N, C, H, W] as a grid image with nrow images per row. |
| `toTensor bitmap device` | Convert an SKBitmap to a [3, H, W] float32 tensor in [0, 1].
 Alpha channel is discarded; output has 3 channels (RGB). |

## fromTensor

```fsharp
fromTensor tensor
```

Convert a [3, H, W] float32 tensor in [0, 1] to an SKBitmap.

**Parameters**

- `tensor` : `Tensor`

**Returns** `SKBitmap`
