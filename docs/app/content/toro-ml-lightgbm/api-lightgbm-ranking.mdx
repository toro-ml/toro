# RankingConfig

Common LightGBM ranking settings.

## Record fields

| Name | Description |
| --- | --- |
| `LearningRate` | Shrinkage rate, or `None` to use ML.NET auto-tuning. |
| `MinimumExampleCountPerLeaf` | Minimum examples per leaf, or `None` to use ML.NET auto-tuning. |
| `NumberOfIterations` | Number of boosting iterations. |
| `NumberOfLeaves` | Maximum number of leaves, or `None` to use ML.NET auto-tuning. |
| `Seed` | Random seed. The default is `Some 0` for reproducibility. |

# Ranking

LightGBM learning-to-rank operations.

| Function | Description |
| --- | --- |
| `evaluate dataset model` | Evaluate a fitted ranker with ML.NET ranking metrics. |
| `fit config dataset` | Fit a LightGBM ranker with common F# settings. |
| `fitWithOptions seed configure dataset` | Fit a LightGBM ranker after configuring the complete ML.NET options object. |
| `load path` | Load a LightGBM ranking model from the ML.NET zip format. |
| `predict features model` | Score a feature matrix. Scores are returned as a detached CPU float32 tensor. |
| `save path model` | Save a fitted model in the ML.NET zip format. |
