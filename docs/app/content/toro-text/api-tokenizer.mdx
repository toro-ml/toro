Microsoft.ML.Tokenizers adapters and factories.

| Function | Description |
| --- | --- |
| `fromBert config` | Create a BERT tokenizer. Encoding adds [CLS]/[SEP] when AddSpecialTokens is true. |
| `fromBpe config` | Create a BPE tokenizer. |
| `fromFunctions encode decode` | Create a tokenizer from encode and decode functions. |
| `fromSentencePiece config` | Create a SentencePiece tokenizer. |
| `fromTiktoken config` | Create a Tiktoken tokenizer. |
| `fromWordPiece config` | Create a WordPiece tokenizer. |
| `inner tokenizer` | Return the wrapped Microsoft.ML.Tokenizers instance.
 Tokenizers created with `fromFunctions` have no backend; this call fails. |
| `wrap inner` | Wrap a Microsoft.ML.Tokenizers tokenizer. |

## fromBert

```fsharp
fromBert config
```

**Parameters**
