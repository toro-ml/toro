# TensorDataView

Shared Tensor and IDataView conversion for algorithm extension packages.

| Function | Description |
| --- | --- |
| `float32Column columnName data` | Copy a scalar float32 IDataView column to a detached CPU tensor. |
| `schema mlContext featureCount` | Create the ML.NET scoring input schema for a feature width. |
| `scoring mlContext features` | Convert a feature matrix to an ML.NET scoring view and return its width. |

## float32Column

```fsharp
float32Column columnName data
```

Copy a scalar float32 IDataView column to a detached CPU tensor.

**Parameters**

- `columnName` : `string`
- `data` : `IDataView`

**Returns** `Tensor`

---

## schema

```fsharp
schema mlContext featureCount
```

Create the ML.NET scoring input schema for a feature width.

**Parameters**

- `mlContext` : `MLContext`
- `featureCount` : `int`

**Returns** `DataViewSchema`

---

## scoring

```fsharp
scoring mlContext features
```

Convert a feature matrix to an ML.NET scoring view and return its width.

**Parameters**

- `mlContext` : `MLContext`
- `features` : `Tensor`

**Returns** `int * IDataView`
