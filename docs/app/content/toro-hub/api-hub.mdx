Download files from the Hugging Face Hub.

| Function | Description |
| --- | --- |

## download

```fsharp
download repoId filename
```

Download a single file from Hugging Face Hub.
 Return the local cache path.

**Parameters**

- `repoId` : `string`
- `filename` : `string`

**Returns** `Async<Result<string, ToroError>>`
