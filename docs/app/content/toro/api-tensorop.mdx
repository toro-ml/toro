# TensorOp

Result-returning arithmetic operators (`+~`, `-~`, `*~`, `/~`) and scalar variants (`*~.` etc.).

| Function | Description |
| --- | --- |
| `a *~ b` | $a \times b$ |
| `t *~. s` | $t \times s$ (scalar) |
| `a +~ b` | $a + b$ |
| `t +~. s` | $t + s$ (scalar) |
| `a -~ b` | $a - b$ |
| `t -~. s` | $t - s$ (scalar) |
| `a /~ b` | $a / b$ |
| `t /~. s` | $t / s$ (scalar) |

## ( *~ )

```fsharp
a *~ b
```

$a \times b$

**Parameters**

- `a` : `^a`
- `b` : `^b`

**Returns** ``Result<Tensor, ToroError>``

# TensorR

Pipeable Result-returning tensor functions (e.g. `tensor |> TensorR.sqrt`).

| Function | Description |
| --- | --- |
| `exp t` | $e^t$ |
| `log t` | $\ln t$ |
| `meanAll t` | Mean of all elements. |
| `neg t` | $-t$ |
| `scale s t` | $s \cdot t$ |
| `shift s t` | $t + s$ |
| `sqr t` | $t^2$ |
| `sqrt t` | $\sqrt{t}$ |
