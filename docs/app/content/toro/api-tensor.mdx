# Tensor module

| Function | Description |
| --- | --- |
| `keep t` | Move a tensor out of the current dispose scope so it
 survives when that scope exits. Inside `scoped { }`,
 return values are auto-kept, so `keep` is only needed
 for side-effect retention (e.g. caching a tensor in a mutable field). |

## keep

```fsharp
keep t
```

Move a tensor out of the current dispose scope so it
 survives when that scope exits. Inside `scoped { }`,
 return values are auto-kept, so `keep` is only needed
 for side-effect retention (e.g. caching a tensor in a mutable field).

**Parameters**

- `t` : `Tensor`

**Returns** `Tensor`
