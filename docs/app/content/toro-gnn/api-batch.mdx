---
title: "Batch"
description: "Batching multiple graphs into a single disconnected graph."
namespace: "Toro.GNN"
---

Combine multiple graphs into a single disconnected graph (PyG-style batching).

## Module functions

| Name | Description |
| --- | --- |
| `Batch.batch graphs` | Combine a list of graphs into one batched graph. Node features are concatenated, edge indices are offset, and a batch vector is created. |
| `Batch.numGraphs g` | Return the number of graphs in a batched graph. |
