Utility functions for graph manipulation.

## Module functions

| Name | Description |
| --- | --- |
| `GraphUtils.addSelfLoops edgeIndex numNodes` | Add self-loops to the edge index. Returns a new edge index with `numNodes` additional edges. |
| `GraphUtils.degree index numNodes dtype device` | Compute node degree from a target index vector. |
