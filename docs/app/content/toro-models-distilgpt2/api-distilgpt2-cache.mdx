A fixed-capacity, per-layer DistilGPT-2 key/value cache.

## Instance members

| Name | Description |
| --- | --- |
| `this.BatchSize` | Number of batch items stored by this cache. |
| `this.Capacity` | Maximum number of tokens stored by this cache. |
| `this.Length` | Number of tokens currently stored by this cache. |
| `this.Reset` | Remove all logical entries without reallocating storage. |
